### Object

1.Object là gì 
- Object ( Đối tượng ): là kiểu dữ liệu lưu trữ 1 tập hợp các cặp key - value 
- Gom lại thành 1 biến duy nhất, dễ quản lý, dễ truyền đi 
record = key ( thuộc tính ) + value (nội dung) 
2. Cách khai báo object 
C1: Object Literal 
vd. let hocSinh ={
       lop: "Lop 12a",
       si so: 45
};
C2: dùng new Object 
-> rối hơn, ưu tiên dùng cách 1
3. Truy xuất dữ liệu 
C1. Dot notation 
C2 Bracket notation ( dùng khi có ký tự đặc biệt )
