2. Kiểu dữ liệu 
- Kiểu dữ liệu: là loại dữ liệu mà biến đó đang mang 
- Có 8 kiểu dữ liệu: 
    - Nguyên thủy ( hay sử dụng ): Number, string, bloolen,...
    - Tham chiếu 
- Kiểu dữ liệu var :biến thay đổi được ( ít dùng , chỉ dùng let và const)



   2.1 **Number** : số nguyên và số thực

3. Các loại toán tử so sánh 

    3.1. So sánh bằng (=)

    `console.log(a===b);`  // kiểm tra nghiêm ngặt ( kiểu dữ liệu, giá trị,...)

    `console.log (a==b);` // kiểm tra giá trị 

    3.2. So sánh khác 

    `console.log(b!==c);`  // khác nghiêm ngặt 

    `console.log(b!=c);`  // khác lỏng lẻo 

    3.3. Toán tử cộng trừ nhân chia (+,-,*,/)
