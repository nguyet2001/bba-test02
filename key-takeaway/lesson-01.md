## Cài đặt 
1. Câu lệnh config git 
- Cài đặt tên bạn :

        git config --global user.name "<tên bạn>" 

- Cài đặt email :

        git config --global user.email "<email của bạn>"

- Cài đặt nhánh mặc định 

        git config --global init.defaultBranch main

2. Khởi tạo dự án playwright 

        npm init playwright@latest


- Câu lệnh tạo SSH Key:

        ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

- Câu lệnh khởi tạo repo Git 

        git init

- Câu lệnh add remote git

        git remote add origin <remote url>

-Câu lệnh thêm code vào vùng staging 

        git add .

- Câu lệnh push code lên GitHub

        git push origin main
